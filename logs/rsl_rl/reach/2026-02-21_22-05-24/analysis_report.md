## 🏆 成功率

该任务**无二元成功/失败判定**，仅有 `time_out` 终止条件：

- `time_out` 率从 **iter 15 起即达到 1.0**（所有 episode 均跑满 360 步后终止）
- 无 early success termination，agent 缺乏"保持在目标"的激励

用 fine-grained tanh 奖励反推（std=0.1）：

```
未归一化奖励 = fine_grained / weight = 0.0494 / 0.1 = 0.494
tanh(d / 0.1) = 0.494  →  d ≈ 5.4 cm（与实测吻合）
```

若以 **3 cm** 为实用精度门槛：当前 5.39 cm **尚未达标**。

## 🩺 问题诊断与优化建议

| 问题 | 根因分析 | 优化建议 |
|------|----------|----------|
| 奖励 iter 184 达峰后下滑 37% | entropy 坍塌，策略过早确定 | 增大 `entropy_coef`：0.001 → 0.005 |
| 位置误差仍 5.5 cm | 训练 iter 不足 | `max_iterations` 增至 3000~5000 |
| 朝向误差后期退化 | 朝向奖励权重（-0.1）弱于位置 | 增大朝向奖励权重至 -0.2 |
| 无成功标志 | 缺少到达目标的 bonus | 添加 success bonus 或 early termination |
| 网络容量偏小 | 64×64 两层 MLP | 尝试 256×128 或 128×128 |
